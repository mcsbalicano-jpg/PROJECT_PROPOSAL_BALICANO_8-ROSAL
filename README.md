# Milestone Maker

Milestone Maker is a program that turns tasks
that compiles them into milestones. Users can create milestones, complete them,
and earn XP as they make progress.

## Planned Features:

- Add new milestones that can connect
- Give each milestone either a duration or time limit
- Earn XP
- Complete milestones
- View active and completed milestones
- Track total XP
